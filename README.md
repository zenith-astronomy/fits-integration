# fits-integration

CLI tool for integrating FITS sub-exposures.

Note: this tool exclusively integrates frames, it does NOT register/align them.

## Available algorithms

- Average
- Median

## Planned algorithms

- Minimum/Maximum

## Planned rejections

- Min/Max
- (Winsorized) Sigma clipping
